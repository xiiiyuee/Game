# 数值体系说明（统一版）

本文档记录《星域幸存者》的数值设计原则、核心公式、关键参数与调参指南。
所有可调参数集中在 [`src/js/01-config.js`](../src/js/01-config.js)，改数值优先改配置，不要在逻辑里写死。

---

## 1. 统一原则

整个项目遵循四条统一规则，新增内容必须沿用：

| 原则 | 含义 | 落地位置 |
| --- | --- | --- |
| **统一成长基准** | 敌人生命、经验、星币使用同一条成长曲线（等效波次 ×1.065），保证“每点生命对应的收益”跨章节恒定 | `waveScaleHp()` / `waveRewardMul()` |
| **统一能量单位** | 超载、技能、补给舱等所有能量回复都按“上限百分比”定义，调整上限时自动适配 | `CFG.ULT.KILL_PCT` / `CFG.EVENTS.POD_ENERGY_PCT` / `CFG.SKILL.FLOW_REFUND_PCT` |
| **统一伤害单位** | 技能/残影/无人机/冲击波伤害一律写成“玩家单发伤害 × 系数”，不写绝对值 | `DMG_MUL` / `SHADOW_DMG` / `WALL_CHARGE_DMG` 等 |
| **统一上限** | 射速、暴击、减伤、敌方射速全部共用 `CFG.LIMITS`，禁止各处写死 | `CFG.LIMITS.MIN_FIRE` / `MAX_CRIT` / `MAX_ARMOR` / `MIN_ENEMY_FIRE` / `MAX_FIRE` |

## 2. 核心公式

### 2.1 玩家输出

```
玩家 DPS = damage × bulletCount × (1 + crit × (critMult − 1)) / fireInterval
```

- 初始值：`10 × 1 × (1 + 0.08 × 1) / 0.26 ≈ 41.5`
- `fireInterval` 下限 `LIMITS.MIN_FIRE = 0.06`
- `crit` 上限 `LIMITS.MAX_CRIT = 0.8`

### 2.2 敌人强度

```
等效波次 t = (chapter − 1) × 10 + (waveNum − 1)

敌人生命 = 基础生命 × 1.065^t × 深渊适应 × 多人加成 × 星域环境
敌人伤害 = 基础伤害 × (1 + 0.055 × (waveNum − 1)) × 1.2^(chapter − 1)
敌人移速 = 基础移速 × min(1.9, 1 + 0.028 × (waveNum − 1) + 0.06 × (chapter − 1))
敌人减伤 = min(0.5, 0.04 × (chapter − 1))
```

### 2.3 深渊适应（防碾压）

```
DPS 倍率 = 玩家当前 DPS / 基准 DPS（基准 = 初始武器配置，1 级时严格为 1）
普通敌人生命倍率 = min(18, DPS 倍率 ^ 0.5)
Boss 生命倍率   = min(3.2, DPS 倍率 ^ 0.28)
```

次线性抬升：玩家越强，敌人越厚，但永远追不上玩家的爆发窗口（大招 / 冲刺 / 技能）。

### 2.4 收益

```
击杀经验 = 基础经验 × 1.065^t
击杀星币 = 基础星币 × 1.065^t
升级需求 = 26 × 1.18^(level − 1)
```

经验与生命同倍率，因此“击杀效率”不会随波次贬值；升级曲线（1.18）低于敌人生长（1.065/波 ≈ 1.88/章），
玩家靠升级 + 技能 + 大招追上难度，而不是靠数值无限膨胀。

## 4. 平衡目标

以 1 级脉冲核心、单机、无走位挂机为基准点（实测）：

| 时间 | 波次 | 等级 | 超载能量 |
| --- | --- | --- | --- |
| 30s | 1 | 1 | 102 / 150 |
| 60s | 2 | 3 | 满 |
| 100s | 4 | 6 | 满 |

- 超载充满约 **35–40 秒**主动输出（约 38 个普通击杀）
- 每章敌人生命 ×1.88、伤害 ×1.2，玩家靠升级（每级约 +8~12% DPS）与技能窗口应对
- 深渊适应确保后期清怪速度不会因为数值爆炸而瞬间蒸发

## 5. 调参指南

| 想改变 | 调什么 |
| --- | --- |
| 整体难度 | `RUN.ENEMY_HP_GROWTH`（每波生命）、`RUN.ENEMY_DMG_GROWTH`（每章伤害） |
| 后期压迫 | `RUN.POWER_ADAPT`（0.5 = 平方根）、`RUN.POWER_CAP` |
| 升级速度 | `XP.BASE` / `XP.GROWTH`（改小 = 升级更快） |
| 超载频率 | `ULT.MAX` / `ULT.KILL_PCT` / `ULT.ELITE_PCT` |
| 超载强度 | `ULT.SLOW_TIME`、`FIRE_MUL`、`DMG_MUL`、`MOVE_MUL`、`DASH_*_MUL` |
| 经济松紧 | `RUN.CREDIT_*`、`RUN.SHOP_PRICE_CHAPTER` |
| 卡牌强度 | `RARITIES[].mult`（保持公比 1.55 递进） |
| 上限类 | `LIMITS.*`（射速/暴击/减伤/射击间隔） |
